# Dark Trap Beats Child Theme

**Client:** Dark Trap Beats  
**Parent Theme:** Twenty Twenty-Five

## Description
This child theme customizes the Twenty Twenty-Five WordPress theme for Dark Trap Beats, a music production website.

## Changes
- Custom dark color palette with purple accents.
- Updated typography and spacing.
- Custom Contact page template.
- Purple Night style variation.
- Custom button and navigation styling.

## Purpose
The child theme keeps custom designs separate from the parent theme so they are preserved during parent theme updates.
